# 服务器执行命令索引

本目录保存需要在 GPU/NPU 服务器执行的命令。每轮操作使用一份带日期和目的的
Markdown 文档，避免从聊天记录或旧的临时文本中复制命令。

## 数据安全边界

服务器数据及运行产物仅在服务器内查看、分析和留存，包括终端输出、日志、JSON、CSV、
Profile trace、模型权重和数据样例。不得将上述内容传至个人电脑、外部聊天工具或未经授权的系统。
跨 GPU/NPU 服务器的参考包流转也必须限定在经批准的内部环境和权限范围内。
历史记录不构成数据流转授权；代码上库前，实验记录和环境快照须按组织要求单独审查。

使用约定：

1. 只复制文档中标有“可整段复制”的 `bash` 代码块；
2. GPU、NPU 和结果汇总命令分开，不跨服务器混用；
3. 每个代码块均从仓库根目录检查开始，并使用 `set -euo pipefail` 在首个错误处停止；
4. 一个反斜杠 `\` 必须是该行最后一个字符；不要在其后添加空格；
5. 不把终端提示符、自然语言说明或输出内容复制进命令；
6. 执行完当前文档的“停止点”后先在服务器内查看结果，再进入下一轮；
7. 历史命令仅用于追溯，实际执行以前以日期最新且状态为“待执行”的文档为准。
8. 每份命令文档必须在“结果路径”中列出完整的仓库相对路径，不只写`$变量/文件名`；
   服务器内优先分析清单和留存备查清单分开列出，便于执行后直接查找。

每轮执行完成后，按[性能调优记录模板](../../实验记录/性能调优记录模板.md)归档原始产物、
结果、分析和决策；失败或无提升的尝试同样保留。
